# Coin icons

Bundled with the app so that no page asks an icon server which coins you hold. Chosen by
`crumenae/icons.py` from the asset's CoinGecko id (or an exchange coin's Binance ticker); coins
without an icon keep a coloured dot.

- **SVG files** (`*.svg`): [spothq/cryptocurrency-icons](https://github.com/spothq/cryptocurrency-icons),
  colour set (coins, and the EUR and USD fiat icons), released under **CC0 1.0** (public domain).
- **PNG files** (`*.png`, 64×64): [trustwallet/assets](https://github.com/trustwallet/assets), MIT
  licence (Copyright (c) 2019-2023 Trust Wallet), resized. Used for coins the set above lacks: LUNA,
  LUNC, USTC, ARB, OP, RON, CELO, MNT, S, MON, SHIB, PEPE, EURC, BUSD, CAKE, FDUSD, JUP, BONK.

Logos are trademarks of their projects and are shown only to identify each coin.
